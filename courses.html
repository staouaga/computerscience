Computer Science Courses

COSC 1301: Introduction to Computing
Overview of computer systems, hardware, operating systems, internet usage, and core software applications including spreadsheets and databases.
COSC 1320: C Programming
Introduction to structured programming techniques using the C language, emphasizing problem-solving, algorithm design, and software development.
COSC 1315: Introduction to Computer Programming
Fundamental concepts of logic, pseudocode, flowcharting, and practical code implementation for introductory engineering and computing majors.
